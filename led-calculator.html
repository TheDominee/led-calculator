4 Wiring diagram

Snake pattern Top-left, down first

Each port takes whole columns or rows at a time, zigzagging (boustrophedon) within its own run — it never breaks mid-column/mid-row. It keeps adding whole columns/rows until the next one would exceed the port's pixel budget or the 1920×1080 per-port rule of thumb (no single port carries more than 1920px of horizontal span or 1080px of vertical span); only then does a new port start. Every new port resets to a forward sweep from the wall's starting edge — it never continues the previous port's zigzag direction — so every cat5 starts cleanly on the same side. Colour = data port, cell labels show Unit.Port and cabinet number along that run, the line traces the physical patch order, and the dot marks where each run plugs into the processor.

6 Complex screen (manual patch)

For a build that isn't a clean rectangle — a circle or triangle made from square panels, pillars set apart from a main screen, or any layout with panels missing or offset — lay out a cabinet grid, mark the panels that aren't there, and hand-patch the rest onto ports yourself. This has its own independent panel and processor settings, separate from sections 1–3 above, so it can plan a one-off build without touching your main wall setup.

Test pattern

Blanked cabinets reserve real space in the pattern at their panel type's resolution (default type, or whatever type you've set for that gap) and render as a transparent cut-out — no signal there, but the surrounding cabinets stay correctly positioned around the gap. A cabinet that's neither blanked nor patched yet isn't reserved at all, so leave patching until last if you want the pattern to reflect the finished layout. Each patched cabinet uses its own panel type's resolution, so if a row or column mixes cabinet sizes, a smaller cabinet leaves a dark margin where it doesn't fill that row/column's full span — a quick visual check for a type mismatch before it goes to site.

5 Layout views

Figures are planning estimates based on published Absen panel and NovaStar processor specifications (MCTRL, VX, NovaPro and H series), and standard rules of thumb (min. viewing distance ≈ pixel pitch in mm × 1, optimal ≈ × 3; port capacity ≈ 650,000px at 8-bit). Confirm final resolution, structural loading, rigging, power/circuit and processor mapping against the manufacturer datasheets before a build. Curved and ring panel counts assume rigid flat panels joined at a fixed bend — check your panel's mechanical bend limit against the angle-per-panel shown. Not an official Absen or NovaStar tool.
